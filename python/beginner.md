## 10. Quel type de données est immuable ?

A. list  
B. tuple  
C. dict  
D. set  

**Bonne réponse :** B. tuple  
**Explication :** Les tuples sont immuables, tandis que les listes sont mutables.
Une valeur immuable est une valeur dont le contenu ne peut pas être modifié sans créer une toute nouvelle valeur, contrairement aux valeurs mutables. En savoir plus [ici](https://developer.mozilla.org/fr/docs/Glossary/Immutable#:~:text=Une%20valeur%20immuable%20est%20une,peut%20%C3%AAtre%20r%C3%A9affect%C3%A9e%20%C3%A0%20une%20autre%20valeur.)
